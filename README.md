# Mirzozoda Abubakr — Portfolio

Portfolio website of Mirzozoda Abubakr, Full Stack Web Developer.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) / React 19
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: GSAP, Framer Motion / Motion, Lenis Smooth Scroll
- **UI Components**: Radix UI, Lucide Icons, Sonner

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
